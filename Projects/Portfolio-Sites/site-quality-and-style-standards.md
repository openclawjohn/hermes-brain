# Portfolio Site Quality & Style Standards

## Core Values
1. **Quality** — Better than good enough. Every time.
2. **Consistency** — Uniform style across all 7 sites.
3. **Over-deliver** — Exceed every minimum. Borderline is failure.

## AdSense Over-Deliver Targets

| Metric | Minimum | Our Target |
|--------|---------|------------|
| Blog posts | 20-30 | **35+** |
| Words per post | 300 | **1,500-3,000** |
| Featured images | Optional | **EVERY post** |
| Total indexable URLs | 25 | **50+** |

## Image Policy
- **USE fal.ai** — never Pexels/Unsplash
- Consistent style per domain (see style guides below)
- Every post needs featured image + in-content image
- Tech quality, relevant to topic
