## User Flow Diagram

```
Google Search
    ↓
Landing Page (Template)
    ↓
┌──────────────────┐
│  User Options:   │
│                  │
│  1. Direct DL    │ → Downloads DOCX immediately
│  2. Preview      │ → Generator page
└──────────────────┘
    ↓
Generator Page
    ↓
┌──────────────────┐
│  Fill Fields:    │
│  - [Name]        │
│  - [Company]     │
│  - [Date]        │
│  - etc.          │
└──────────────────┘
    ↓
┌──────────────────┐
│  User Actions:   │
│                  │
│  1. Download     │ → Custom DOCX with data
│  2. Print        │ → Browser print dialog
│  3. Browse More  │ → Category page
└──────────────────┘
    ↓
AdSense Impressions (5-7 per session)
    ↓
User Satisfied → Returns/Shares
```
